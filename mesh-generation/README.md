# Mesh Generation Research Watch

This research stream tracks academic advances in mesh generation for engineering simulation, with emphasis on CAE, CFD, FEM, computational geometry, and scientific computing.

## Scope

Priority topics include:

- automated mesh generation;
- adaptive and anisotropic meshing;
- differentiable meshing;
- solver-in-the-loop mesh optimization;
- reinforcement learning and self-play for meshing;
- Transformer-based methods;
- graph neural networks;
- topology-aware meshing;
- geometry-aware learned representations;
- hybrid neural-classical pipelines;
- mesh quality, robustness, and validity;
- generalization across geometries and simulation regimes.

## Research objective

The goal is to identify methods that materially improve the reliability, automation, quality, efficiency, or generality of meshing workflows used in engineering simulation.

The research should distinguish between incremental benchmark improvements and deeper changes in how meshing is formulated, learned, optimized, or coupled to downstream solvers.

## Research memory

`research.md` is the living memory for this research stream. Each scheduler run should read the current document before searching and revise it in place rather than create a new dated report.

The document should preserve primary-source links, dates, methodological contributions, evidence and evaluation setup, mesh-quality or downstream-solver metrics, practical constraints, limitations, assumptions, failure modes, and relevance to CAE, CFD, FEM, or scientific-simulation pipelines. Prior methods or claims should be marked as still relevant, strengthened, weakened, contradicted, superseded, or deprioritized when appropriate.

Useful historical material should remain available in compact archival sections instead of being silently deleted, while the main body should reflect the best current view of promising approaches and their production viability.
