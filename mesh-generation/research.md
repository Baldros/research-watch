# Mesh Generation — Mathematical Research Map

_Last reviewed: 2026-11-07 (America/Sao_Paulo). The current two-pillar scope supersedes the older broad AI-first organization. Older relevant material is preserved in a compact continuity section._

## Executive assessment

This research stream is now organized around two mathematical pillars:

1. **Statistical and probabilistic understanding of meshes and mesh quality.**
2. **Mathematical foundations of advancing-front generation**, with emphasis on triangular surface meshing.

The main conceptual change is that mesh quality should not be treated only as a collection of deterministic scores or histograms. A mesh run can be viewed as a random object once a sampling mechanism is specified, and the observed quality values form a dependent marked structure generated by geometry, the front state, scheduling, candidate placement, closure events, and any algorithmic randomness.

At the same time, advancing-front methods have more mathematical structure than a purely heuristic description suggests. In particular, there are classical sufficient-condition results for finite termination and valid triangulation in planar advancing-front frameworks. This corrects an overly broad claim in the project notes that advancing-front methods have no termination guarantees.

The current working synthesis is:

> **Geometry and metric determine admissible local configurations; the front algorithm generates a history-dependent sequence of transformations; probability/statistics describe the variability and dependence induced by inputs and decisions; deterministic geometric predicates and invariants establish validity; downstream PDE error is a separate question.**

No reviewed work establishes a universal probability law for advancing-front mesh quality, nor a production-grade learned policy with theorem-level guarantees on arbitrary trimmed CAD surfaces.

## 0.2 Five quantities that must remain distinct

1. **Geometric/topological validity**  
   No forbidden intersections, correct incidence and orientation, correct CAD boundary, positive Jacobian where required.

2. **Element shape quality**  
   Angles, aspect/shape measures, scaled Jacobian, mean ratio, condition-type measures.

3. **Geometric fidelity**  
   Approximation of CAD curves/surfaces, normal error, curvature error, Hausdorff-type errors.

4. **Numerical-solution quality**  
   Interpolation error, consistency, conditioning, solver convergence, PDE error.

5. **Statistical behavior**  
   Distributions and dependence induced by variation in geometry, algorithm configuration, scheduling, random seeds, or other sampling mechanisms.

A result on one axis does not automatically imply a result on another.

## 0.3 Metric-definition discipline

The project notes correctly flag that identically named metrics may have different definitions and directions.

For example, ICEM uses several normalized metrics with **1 = ideal**, whereas Fluent-style skewness conventions often use **0 = ideal**. “Aspect Ratio” is not a universal scalar with one formula.

For triangular shape analysis, a useful explicitly scale-free reference quantity is

\[
q_A(T)=
\frac{4A(T)}
{\sqrt{3}\,L_{\max}(T)^2}
\in[0,1],
\]

which equals 1 for the equilateral triangle and tends to 0 under flattening. This is a mathematical reference quantity, not a claim that every commercial “Aspect Ratio” implementation evaluates precisely this formula.

Before statistical modeling, record:

- exact formula;
- element family;
- support;
- units;
- ideal/worst direction;
- whether invalid elements are clipped, excluded, or assigned special values;
- normalization;
- evaluation points;
- conditioning variables.

For a triangle with angles \(\alpha,\beta,\gamma\),

\[
\alpha+\beta+\gamma=\pi.
\]

Thus the three angles are structurally dependent and should not be modeled as three independent random variables.

# PILLAR I — Statistical and probabilistic understanding of meshes

## 1. Probability space before distribution fitting

Let

- \(D\) be the CAD/domain,
- \(c\) the mesher configuration,
- \(\mathcal A\) the generation algorithm,
- \(U\) the explicitly defined source of randomness or experimental variation.

Then

\[
M=\mathcal A(D,c,U),\qquad U\sim P_U.
\]

The **entire generated mesh \(M\)** is the random object.

Let

- \(N(M)\) be its number of elements,
- \(\mathcal T(M)\) its triangle set,
- \(q(T)\) a precisely defined quality metric.

Different observation schemes induce different probability distributions.

### 1.1 Four non-equivalent sampling schemes

**Run first, then triangle**

Draw a run and then a triangle uniformly inside that run:

\[
F_{\mathrm{run}}(z)
=
\mathbb E
\left[
\frac{1}{N(M)}
\sum_{T\in \mathcal T(M)}
\mathbf 1\{q(T)\le z\}
\right].
\]

**Pool all triangles**

Pooling every triangle from all runs estimates a size-biased object approximately proportional to

\[
\frac{
\mathbb E[\sum_T \mathbf 1\{q(T)\le z\}]
}{
\mathbb E[N(M)]
}.
\]

Runs producing more elements receive greater weight.

**Spatial/area-weighted element**

Sample a point uniformly from the physical domain and inspect the triangle containing it. Large triangles receive more probability mass.

**Worst element per run**

For a 1-good / 0-bad metric,

\[
W(M)=\min_{T\in\mathcal T(M)} q(T).
\]

This is an extreme-value statistic, not the marginal element-quality distribution.

These distributions answer different scientific questions.

## 2. Direct current evidence: nondeterministic mesh quality

### Parry, Winovich & Owen — Learning-Based Prediction of Tetrahedral Mesh Quality under Nondeterministic Meshing

SIAM International Meshing Roundtable 2026, published online 2026-06-04.  
Primary: https://doi.org/10.1137/1.9781611979138.20

The work repeatedly generates tetrahedral meshes and studies variability in local minimum scaled Jacobian near CAD features.

### Mathematical contribution

The relevant object is a **conditional distribution of a quality extreme given geometric/configuration information**.

The work predicts location/quality-risk quantities and a notion of dispersion. It therefore goes beyond a single deterministic “mesh quality” number.

### What is supported

- repeated meshing generates measurable quality variability;
- geometric/CAD information explains part of this variability;
- uncertainty-aware prediction can identify risky regions/configurations.

### What is not established

The work does not establish a universal parametric family for mesh quality, statistical sufficiency of the selected features, an explicit spatial dependence law for all elements, or transfer to arbitrary advancing-front surface meshes.

### Connection to this project

This is currently the strongest direct precedent for separating:

\[
\text{run-to-run variation}
\]

from

\[
\text{within-mesh element variation}.
\]

**Status: newly incorporated / high priority.**

## 3. Why the minimum quality has its own probability law

Suppose, only as a null model, that

\[
Q_1,\ldots,Q_n
\]

are iid with CDF \(F\), where lower quality is worse.

Then

\[
P(\min_i Q_i>z)
=
[1-F(z)]^n,
\]

hence

\[
P(\min_i Q_i\le z)
=
1-[1-F(z)]^n.
\]

Even with the same marginal \(F\), merely increasing the number of elements makes worse minima more likely.

If \(N\) is random,

\[
P(W>z)
=
\mathbb E[(1-F(z))^N]
\]

under the strong conditional-iid assumption.

For a real advancing-front mesh, this assumption is generally implausible because:

- geometry changes over space;
- the front creates local dependence;
- closure regions behave differently;
- \(N\) is generated by the policy;
- nearby triangles share vertices and ancestry;
- quality failures may occur in clusters.

Thus the iid extreme-value formula should be treated as a **diagnostic null hypothesis**, not a model of truth.

## 4. Stochastic geometry as an explanatory comparison class

### Chiu — Spatial Point Pattern Analysis by Using Voronoi Diagrams and Delaunay Tessellations

Biometrical Journal 45(3), 367–376, 2003.  
Primary: https://doi.org/10.1002/bimj.200390018

### Mathematical idea

Start from a random planar point process, construct its Voronoi/Delaunay tessellation, and use triangle geometry as statistics of the underlying point process.

The geometry of the triangles is therefore not merely “quality output”; it contains information about the mechanism that generated the point pattern.

### Relevant result

The study reports that triangle minimum angle responds to regularity and clustering, while quantities such as area and perimeter have different sensitivities.

### Why it matters here

This establishes a useful conceptual precedent:

\[
\text{distribution of mesh geometry}
\quad\Longleftrightarrow\quad
\text{structure of the generating process}.
\]

For advancing fronts, the generating process is not Poisson or stationary, but the same question becomes natural:

> Which observed quality distributions are explained by front scheduling, candidate construction, CAD geometry and closure history?

### Limitation

Advancing-front inserted vertices are not an unconstrained stationary point process. Poisson-Delaunay theory is therefore a **comparison/null model**, not a fitted theory of the mesher.

**Status: foundational / high explanatory priority.**

## 5. Explicit probability laws in Poisson–Delaunay geometry

### Rathie — On the Volume Distribution of the Typical Poisson–Delaunay Cell

Journal of Applied Probability, 2016.  
Primary: https://www.cambridge.org/core/journals/journal-of-applied-probability/article/on-the-volume-distribution-of-the-typical-poissondelaunay-cell/307FB451B478536B6B9523C02B13F686

### Xia & Aïssa — Unified Analytical Volume Distribution of Poisson-Delaunay Simplex

Primary preprint: https://arxiv.org/abs/1805.01023

These works illustrate something useful for this research program: an explicit quality/geometry distribution is meaningful only after the random construction and sampling convention have been defined.

A “typical Delaunay cell” is defined through stochastic-geometric sampling conventions; it is not automatically the same object as:

- a uniformly selected mesh triangle;
- the triangle containing a uniformly sampled spatial point;
- a triangle created at a random front step;
- the worst triangle of a run.

**Status: foundational statistical comparison class.**

## 6. Proposed conditional model for advancing-front quality

For the triangle produced at front step \(t\), define

\[
Q_t=q(T_t).
\]

Let the explanatory state include

\[
Z_t=
(
\ell_M,
\kappa,
\sigma_1/\sigma_2,
d_{\mathrm{front}},
\text{clearance},
\text{insert/reuse},
\text{ancestry},
\text{closure type},
t/N,
\ldots
).
\]

The main statistical object is

\[
F(q\mid z)
=
P(Q_t\le q\mid Z_t=z).
\]

Potential explanatory models, in increasing structural complexity:

1. empirical marginal CDF;
2. stratified conditional CDF;
3. hierarchical mixed-effects model with CAD/run effects;
4. spatial or graph-dependent marked model;
5. history-dependent sequential model.

A Beta or logistic-normal family may be attempted for interior values in \((0,1)\), but it should not be imposed solely because the support is bounded. Exact 0/1 masses, multimodality and conditional heterogeneity may require different models.

### Model assessment

Evaluate:

- probability calibration;
- PIT / QQ diagnostics when appropriate;
- held-out CAD families;
- blocked bootstrap by **mesh run**;
- residual spatial/front correlation;
- lower-tail calibration;
- robustness to metric definition;
- whether adding ancestry/history materially reduces unexplained dependence.

Complexity is not itself a virtue.

## 7. Sufficiency: model-specific, not rhetorical

For a model family

\[
p(x\mid\theta),
\]

a statistic \(S(X)\) is sufficient for \(\theta\) only when the conditional law

\[
P(X\mid S(X),\theta)
\]

does not depend on \(\theta\), equivalently under standard dominated settings through the factorization criterion.

Therefore:

- a histogram is not automatically sufficient;
- mean/variance are not automatically sufficient;
- a learned embedding is not sufficient merely because prediction remains accurate;
- a topological or geometric descriptor can be called sufficient only relative to a specified stochastic model and parameter.

This point is central if future work claims that a reduced representation captures “all the information needed” for mesh quality.

# PILLAR II — Mathematical foundations of advancing fronts

## 8. Termination: an important correction

### Farestam & Simpson — A Framework for Advancing Front Techniques of Finite Element Mesh Generation

University of Waterloo report, 1993.  
Primary repository: https://uwspace.uwaterloo.ca/items/21bd25fb-9392-4d3b-8bef-57066145157f

### Mathematical idea

The paper decomposes a planar advancing-front method into subtasks and gives **sufficient conditions** under which an algorithm satisfying them terminates after finitely many steps and yields a valid triangulation.

### What is proved

The theorem is conditional:

\[
\text{AFT satisfies stated subtask conditions}
\Longrightarrow
\text{finite valid triangulation}.
\]

It is not a proof that every advancing-front policy terminates.

### Direct consequence for the project

The broad claim

> “advancing-front methods have no termination theorem”

is **contradicted**.

A more accurate statement is:

> A particular scheduling/candidate policy does not inherit a termination guarantee unless one verifies the hypotheses of an applicable framework.

This suggests a concrete task: map the current implementation to the sufficient conditions and identify which invariant or subtask lacks proof.

**Status: foundational / high-priority correction.**

## 9. Stalling and constrained recovery

### Philip Caplan — An advancing-ridge approach for recovering boundary (d−1)-simplices in d-dimensional meshes

arXiv, 2026-08-15.  
Primary: https://arxiv.org/abs/2608.15176

The algorithm advances a front of lower-dimensional ridges and uses constrained cavity operations. Steiner insertion is used to resolve some stalled situations.

### Why it matters

It gives a mathematically clean engineering pattern:

\[
\text{local failure}
\rightarrow
\text{detect stalled state}
\rightarrow
\text{constrained cavity/retriangulation}
\rightarrow
\text{Steiner insertion if needed}.
\]

A front algorithm need not treat every failure as global failure.

### Evidence boundary

The reported recovery rates and 4D experiments are empirical evidence, not a universal completeness theorem for trimmed CAD surface meshing.

**Status: 2026 / high conceptual transfer value.**

## 10. Front state, scheduling and ancestry

Define the complete state

\[
X_t=
(
F_t,
V_t,
\mathcal T_t,
G_t,
B_t,
H_t
),
\]

where \(H_t\) records any ancestry/history used by the scheduler.

An action consists of an active edge and a construction operation:

\[
a_t=(e_t,\text{candidate/reuse/closure decision}).
\]

A deterministic policy is

\[
a_t=\pi(X_t),
\]

whereas a randomized implementation is described by

\[
a_t\sim K(\cdot\mid X_t).
\]

If ancestry affects the policy but is omitted from the state, the reduced process need not be Markov.

### Dimensional issue in the current score

The project notes use

\[
s_e=d_e+\alpha\ell_e.
\]

If

- \(d_e\) is dimensionless,
- \(\ell_e\) has units of length,

then

\[
[\alpha]=L^{-1}.
\]

Thus \(\alpha\) cannot be interpreted independently of the unit system unless the length term is normalized.

A more geometrically meaningful comparison can use metric length

\[
\ell_M(e)
=
\int_e
\sqrt{\dot\gamma^\top M(\gamma)\dot\gamma}\,ds,
\]

or an appropriate discrete approximation.

Then

\[
s_e=d_e+\alpha \ell_M(e)
\]

can be made dimensionless.

### Statistical bridge

A concrete hypothesis is:

> Two front states with nearly identical local geometry but different ancestry may have different conditional probabilities of poor closure or poor element quality.

This is testable by comparing models

\[
P(Q_t\mid Z_t)
\]

and

\[
P(Q_t\mid Z_t,H_t).
\]

This directly connects the two pillars.

## 11. Parallel scheduling and reproducibility

### Ma, Huang, Luo & Yang — CPAFT

**CPAFT: A Consistent Parallel Advancing Front Technique for Unstructured Triangular/Tetrahedral Mesh Generation**  
Primary: https://arxiv.org/abs/2405.20618

The method combines decomposition with consistent parallel maximal independent set selection and argues that the generated result is independent of processor count/decomposition under the method's rules.

### Why it matters statistically

Before assigning a probability law to “mesher randomness,” identify which variability sources are:

- deliberate;
- numerical;
- ordering-based;
- parallel-race artifacts;
- geometry/input variation.

A parallel algorithm designed for consistency can remove one source of apparent randomness.

**Status: still relevant; direct connection between deterministic algorithm design and statistical interpretation.**

## 12. Classical front selection and local repair

### Rassineux — Generation and Optimization of Tetrahedral Meshes by Advancing Front Technique

IJNME, 1998.  
Primary: https://doi.org/10.1002/(SICI)1097-0207(19980228)41:4%3C651::AID-NME304%3E3.0.CO;2-P

Front faces are selected in relation to predicted quality of available tetrahedra, with local replacement/repair when standard advancement fails.

This is a direct classical precedent for treating scheduling as a quality-aware decision problem.

**Limit:** 3D tetrahedral setting; not a universal theorem and not triangular CAD surface generation.

# 14. Riemannian metrics, CAD charts and anisotropy

Let

\[
S:U\subset\mathbb R^2\rightarrow\mathbb R^3
\]

be a regular CAD parametrization with

\[
J=DS,\qquad \operatorname{rank}J=2.
\]

The first fundamental form / pullback metric is

\[
G=J^\top J.
\]

For a parameter-space vector \(v\),

\[
v^\top Gv
=
\|Jv\|^2.
\]

Therefore Euclidean length in parameter space is generally not physical surface length.

## 14.1 SVD interpretation

Let

\[
J=U
\begin{bmatrix}
\sigma_1&0\\
0&\sigma_2\\
0&0
\end{bmatrix}
V^\top,
\qquad
\sigma_1\ge\sigma_2>0.
\]

Then

\[
G=
V
\begin{bmatrix}
\sigma_1^2&0\\
0&\sigma_2^2
\end{bmatrix}
V^\top.
\]

Hence

\[
\frac{\sigma_1}{\sigma_2}
\]

measures **local chart anisotropy/stretching**.

It is **not curvature**.

Curvature depends on derivatives of the normal / second fundamental form, whereas \(G\) is first-order metric information.

This distinction should remain explicit in project notes and implementations.

## 14.2 Target-size metric

If \(h(q)>0\) is the desired isotropic physical edge size, then

\[
M(q)=\frac{G(q)}{h(q)^2}
\]

makes metric unit length correspond to target physical length.

More generally, with a physical anisotropic SPD metric \(H(x)\),

\[
M(q)
=
J(q)^\top H(S(q))J(q).
\]

This is the natural pullback to the parameter chart.

# 17. Front propagation as PDE: an important mathematical analogy

### Aubry et al. — An Entropy Satisfying Boundary Layer Surface Mesh Generation

SIAM Journal on Scientific Computing 37(4), A1957–A1974, 2015.  
Primary: https://doi.org/10.1137/140963625

The generation of surface layers is connected to weak/entropy solutions of an Eikonal-type front propagation problem.

### Why it matters

Some collision and concavity phenomena can be interpreted using a front-propagation PDE and an admissibility principle, rather than only as a list of implementation corner cases.

This does not imply every advancing-front mesher is an Eikonal solver. It is a mathematically useful model for a specific class of advancing layers.

**Status: foundational / high transfer value.**

# 18. Robust predicates and admissibility

### Shewchuk — Adaptive Precision Floating-Point Arithmetic and Fast Robust Geometric Predicates

Discrete & Computational Geometry 18, 1997.  
Primary: https://doi.org/10.1007/PL00009321

Adaptive exact predicates refine arithmetic only when floating-point filters cannot certify the sign.

This is directly relevant to

\[
\operatorname{orient}(A,B,C)
\]

and intersection decisions.

### Critical distinction

Exact sign answers:

> On which side?

It does not answer:

> Is this configuration numerically/geometrically too close to degeneracy?

A separate scale-invariant quality quantity is needed.

For two incident vectors \(u,v\),

\[
\frac{|\det[u,v]|}{\|u\|\|v\|}
=
|\sin\theta|
\]

is dimensionless and detects near-collinearity.

This validates the project note's proposed normalization as a natural local angle test, while not making it a complete mesh-quality criterion.

# 20. Connection between the two pillars: a stochastic advancing-front process

At step \(t\), define

\[
X_t
=
\text{complete front state},
\]

\[
E_t
=
\text{selected front edge},
\]

\[
A_t
=
\text{candidate/reuse/closure action},
\]

\[
Q_t
=
\text{quality of the resulting triangle}.
\]

The central probabilistic object is

\[
P(E_t,A_t,Q_t\mid X_t,H_t,D,M).
\]

If the algorithm is fully deterministic under fixed inputs, this is a Dirac kernel. Probability enters only after defining variation in:

- seed;
- ordering;
- geometry population;
- configuration;
- parallel scheduling;
- perturbations;
- measurement/sampling.

## Research hypothesis H1 — ancestry carries information

Compare

\[
P(Q_t\mid Z_t)
\]

against

\[
P(Q_t\mid Z_t,H_t),
\]

where \(H_t\) contains parent depth, age or front lineage.

If history improves conditional calibration after controlling for geometry, the process is genuinely history-dependent at the chosen state resolution.

## H2 — poor-quality elements cluster by process mechanism

Test whether low-quality events are concentrated around:

- closure;
- collision;
- high chart anisotropy;
- high curvature;
- reuse events;
- old front branches;
- local front congestion.

This is stronger than showing a skewed histogram.

## H3 — geometry and scheduling contribute separately

Run factorial experiments where candidate construction and metric remain fixed while front scheduling changes. Then reverse the experiment.

This permits a much cleaner causal interpretation than comparing entire meshers.

# 21. Experimental protocol

## 21.1 Statistical dataset

For every generated triangle record:

- run ID and seed;
- CAD model / patch;
- mesher version/configuration;
- step index;
- active edge ID;
- parent/ancestry information;
- insertion versus reuse;
- closure event type;
- front local degree / clearance;
- physical edge length;
- metric length;
- \(G=J^\top J\);
- singular values \(\sigma_1,\sigma_2\);
- principal curvatures when available;
- local target \(h\);
- exact quality metrics and normalization;
- CAD deviation;
- neighbor relationships;
- final status of the run.

Do not treat triangles from one run as statistically independent replicates.

## 21.2 First analyses

1. marginal empirical quality distribution;
2. run-balanced distribution;
3. area-weighted distribution;
4. distribution of worst element per run;
5. quality versus front step;
6. conditional distributions by operation/closure type;
7. spatial/front-neighborhood autocorrelation;
8. effect of ancestry;
9. lower-tail clusters;
10. held-out CAD-family validation.

## 21.3 Advancing-front theorem audit

Map the current implementation against Farestam–Simpson-style hypotheses.

For each operation ask:

- does it strictly reduce or otherwise progress a finite admissible state?
- can it recreate a previous front configuration?
- can it create self-intersection?
- can it trap a hole?
- does a local stalled state have a fallback?
- are exact predicates used for all topological decisions?
- what invariant establishes correctness after each update?

## 21.4 Parameterization invariance tests

Use manufactured surfaces:

- plane;

# 22. Ranked research priorities

1. **Termination/correctness audit against Farestam–Simpson.**  
   Directly resolves an open project claim and can expose implementation invariants.

2. **Repeated-run statistical study inspired by Parry–Winovich–Owen.**  
   Build a proper probability space for current advancing-front data.

3. **Conditional triangle-quality distributions.**  
   Explain geometry, scheduling, ancestry and closure effects rather than fitting one global histogram.

4. **Stochastic-geometry comparison models.**  
   Use Poisson/inhibited/clustered Delaunay processes as explicit nulls, not as assumed truths.

5. **Riemannian AFT and chart-invariance tests.**  
   Connect \(G=J^\top J\), \(M=G/h^2\), SVD anisotropy and actual candidate placement.

6. **Stall/recovery mechanisms.**  
   Study cavity/retriangulation/Steiner strategies using Caplan and classical AFT literature.

7. **Robust-predicate and near-degeneracy separation.**  
   Exact topology decision plus independent geometric quality threshold.

8. **Only then: learned scheduling or policy.**  
   ML/RL should be evaluated against the explanatory and correctness baselines above.

# 24. Claims revised in this review

| Claim | Current status |
| --- | --- |
| Advancing-front methods have no termination theorem | **Contradicted in this unrestricted form.** Sufficient-condition planar results exist. |
| A histogram characterizes mesh-quality randomness | **Weakened.** Sampling scheme, dependence and conditioning matter. |
| Pooled triangles are independent observations | **False in general.** Shared geometry/front history induces dependence. |
| The minimum quality can be compared across meshes without accounting for element count | **False in general.** Extreme-value behavior depends on sample size and dependence. |
| \(\sigma_1/\sigma_2\) of the surface Jacobian measures curvature | **False.** It measures local parameterization stretching. |
| \(M=G/h^2\) is an isolated project heuristic | **Contradicted.** It belongs to the classical Riemannian metric meshing framework. |
| A single geometric quality metric determines numerical accuracy | **False in general.** Shape, fidelity, interpolation, conditioning and PDE error are distinct. |
| Observed run variation proves the mesher is intrinsically probabilistic | **False.** First identify the sampling/randomization mechanism. |
| Modern ML has replaced advancing-front geometric kernels | **Not supported.** Hybrid learned-decision/classical-validity approaches remain more credible. |

# 25. Working research thesis

The emerging research question is not simply:

> “Which mesh-quality metric is best?”

nor:

> “Which neural architecture generates the best mesh?”

It is:

\[
\boxed{
\text{How do geometry, metric, front history and local decisions generate the joint distribution of mesh configurations and quality?}
}
\]

and, separately,

\[
\boxed{
\text{Which deterministic invariants and fallback mechanisms guarantee that the advancing process remains geometrically and topologically valid?}
}
\]

Only after those two questions are understood does it become meaningful to ask whether a learned policy improves the process.
